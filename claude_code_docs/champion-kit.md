# 챔피언 킷 (Champion kit)

> 팀 내에서 Claude Code 사용을 권장하고 주도하는 엔지니어를 위한 플레이북: 공유할 내용, 질문에 답하는 방법, 팀 전반의 도입을 늘리는 방법.

이 페이지는 이미 Claude Code를 사용하고 있으며 팀 내 도입을 돕고자 하는 엔지니어를 위한 가이드입니다. 공유할 내용, 주요 질문 답변법, 30일 실행 플레이북, 일반적인 우려 사항에 대한 대응법을 다룹니다.

## 챔피언 역할의 핵심 행동

1. **발견한 내용 공유하기**: 프롬프트, 스크린샷, 소소한 성공 사례를 팀 슬랙 채널이나 PR 설명에 공유하세요.
2. **질문에 답변해 주는 사람 되기**: 동료가 어떻게 해결했는지 물어보면 실제로 사용한 프롬프트를 공유하세요.
3. **서클 키우기**: 주간 공유 스레드 등 지속 가능한 가벼운 습관을 만드세요.

## 시간 소요 제안

* 성과 및 프롬프트 공유: 주당 약 15분
* 공유 채널 질문 답변: 주당 약 20분
* 주간 공유 스레드 진행: 주당 약 5분
