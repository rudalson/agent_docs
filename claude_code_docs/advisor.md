# 어드바이저(advisor) 도구로 어려운 결정 에스컬레이션하기

> 메인 모델과 더 강력한 어드바이저 모델을 짝지어, 작업의 주요 순간마다 Claude가 자문을 구하도록 설정합니다.

<Note>
  어드바이저 도구는 실험적 기능이며 Anthropic API가 필요합니다. Amazon Bedrock, AWS의 Claude Platform, Google Cloud's Agent Platform 또는 Microsoft Foundry에서는 사용할 수 없습니다. 동작 방식, 가격 및 사용 가능 여부는 변경될 수 있습니다.
</Note>

어드바이저 도구를 사용하면 Claude가 접근 방식을 확정하기 전, 반복되는 오류로 막혔을 때, 작업을 완료로 선언하기 전과 같이 작업 중 주요 순간에 일반적으로 더 강력한 두 번째 모델에 자문을 구할 수 있습니다. 어드바이저는 모든 도구 호출 및 결과를 포함한 전체 대화를 수신하고, Claude가 계속 진행하기 전에 적용할 지침을 반환합니다.

어드바이저는 구독 계정과 API 청구 계정 모두에서 사용할 수 있으며 Anthropic 인프라의 [서버 도구](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool)로 서버 측에서 실행됩니다. 어떤 모델이 어드바이저 역할을 할지는 사용자가 선택하며, 언제 이를 호출할지는 Claude가 결정합니다.

이 페이지에서는 어드바이저 활성화 방법, 허용되는 모델 조합, 자문 구하는 동안 Claude가 표시하는 내용, 어드바이저 사용량의 청구 방식을 설명합니다.

## 어드바이저를 사용하는 경우

어드바이저는 대부분의 턴은 일상적이지만 계획의 품질이 결과를 결정짓는 긴 다단계 작업에 적합합니다. 주요 예로는 대규모 리팩토링, 오류가 계속 반복되는 디버깅 세션, Claude가 작업을 완료했다고 선언하기 전에 독립적인 검증을 받고 싶은 작업 등이 있습니다.

계획할 내용이 거의 없는 짧은 작업이나 모든 턴마다 가장 강력한 모델이 필요한 작업에서는 가치가 떨어집니다. 이러한 작업에서는 [메인 모델을 전환](/docs/en/model-config#setting-your-model)하거나, 제2의 의견을 얻는 다른 방법을 다룬 [opusplan 및 서브에이전트와의 비교](#관련-기능과의-비교)를 참조하세요.

## 어드바이저 활성화하기

어드바이저 모델은 세 가지 방법으로 설정할 수 있습니다:

* **`/advisor` 명령**: 세션 중간에 어드바이저를 설정하거나 변경하고 기본값으로 저장
* **`advisorModel` 설정**: [설정 파일](/docs/en/settings)에서 영구 기본값으로 구성
* **`--advisor` 플래그**: 실행 시 단일 세션에 대해 어드바이저 설정

이 중 하나로 어드바이저 모델을 설정하면 메인 모델이 [이를 지원하는](#어드바이저-모델-선택하기) 세션에서 어드바이저가 활성화되며, 세션 시작 후 `Advisor Tool (experimental) is on and may use more tokens · /advisor` 알림이 표시됩니다. 사용을 중지하려면 [어드바이저 끄기](#어드바이저-끄기)를 참조하세요.

<Note>
  {/* min-version: 2.1.210 */}Claude Code는 Fable 5를 어드바이저로 제공하지 않습니다. [Fable 5 접근 권한](/docs/en/model-config#work-with-fable-5)이 있는 조직의 경우에도 `/advisor` 선택기에는 `Fable 5 (temporarily unavailable)`이라는 레이블과 함께 비활성화된 선택 불가 행으로 표시되며, Claude Code는 `/advisor fable` 및 `--advisor fable`을 거부합니다. 메인 모델로서의 Fable 5는 영향받지 않습니다.

  원격으로 구성된 롤아웃에 따라 Fable 5가 어드바이저 옵션으로 다시 제공되는 시점이 제어됩니다.
</Note>

### `/advisor` 명령 사용하기

인자 없이 `/advisor`를 실행하여 사용 가능한 어드바이저 모델 목록 선택기를 열거나, 모델을 직접 전달하세요:

```
/advisor opus
```

이 명령은 `Advisor set to`와 어드바이저 모델 이름을 출력하여 확인합니다. 선택한 항목은 사용자 설정의 `advisorModel`에 저장되며 세션 간에 유지됩니다.

조직의 [`availableModels`](/docs/en/model-config#restrict-model-selection) 허용 목록에서 저장된 어드바이저 모델을 제외하는 경우 `/advisor`로 허용된 모델을 선택할 때까지 어드바이저가 호출되지 않습니다. 현재 메인 모델이 어드바이저를 지원하지 않더라도 선택 사항은 저장되며, [`/model`](/docs/en/model-config#setting-your-model)을 통해 [호환되는 메인 모델](#어드바이저-모델-선택하기)로 전환할 때 활성화됩니다.

### 설정에서 `advisorModel` 지정하기

세션을 열지 않고 어드바이저를 기본값으로 구성하려면 설정 파일에 지정하세요:

```json theme={null}
{
  "advisorModel": "opus"
}
```

### `--advisor` 플래그 사용하기

저장된 설정을 변경하지 않고 단일 세션에 대해 어드바이저를 설정하려면 플래그와 함께 실행하세요:

```bash theme={null}
claude --advisor opus
```

이 플래그는 해당 세션 동안 `advisorModel` 설정보다 우선하며 `claude --help`에는 나열되지 않습니다. 세션의 메인 모델이 어드바이저를 지원하지 않거나 요청된 어드바이저 모델이 조직의 [`availableModels`](/docs/en/model-config#restrict-model-selection) 허용 목록에서 제외된 경우 오류를 내며 종료됩니다.

## 어드바이저 모델 선택하기

어드바이저는 최소한 메인 모델만큼 성능이 뛰어난 모델이어야 합니다. Fable 5는 성능 점검 기준을 충족하지만 [어드바이저로 제공되지 않으므로](#어드바이저-활성화하기), 다음 표의 Fable 항목은 롤아웃을 통해 옵션으로 다시 제공될 때 적용됩니다. 각 메인 모델에 허용되는 어드바이저는 다음과 같습니다:

| 메인 모델 | 허용되는 어드바이저 | 참고 사항 |
| ----------------------------------------------- | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Haiku 4.5 | Fable, Opus, Sonnet | Haiku는 어드바이저를 호출할 수 있지만 어드바이저 역할을 할 수는 없음 |
| Sonnet 4.6 | Fable, Opus, Sonnet | |
| Sonnet 5 | Fable, Opus, Sonnet 5 | Sonnet 4.6 어드바이저는 거부됨 |
| Opus 4.6 | Fable, Opus, Sonnet 5 | Sonnet 5와 Opus 4.6은 동일한 성능 수준으로 순위가 매겨지므로 Opus 4.6 메인은 Sonnet 5 어드바이저를 허용함 |
| Opus 4.7 이상 | Fable, Opus 4.7, Opus 4.8 | Opus 4.7과 Opus 4.8은 동일한 성능 수준으로 순위가 매겨지므로 둘 다 서로를 어드바이저로 허용함. Opus 4.6 또는 Sonnet 5 어드바이저를 사용하는 Opus 4.7 메인은 거부됨 |
| Fable 5 ({/* min-version: 2.1.170 */}v2.1.170+) | Fable | Opus 또는 Sonnet 어드바이저는 거부됨. Fable은 어드바이저로 제공되지 않으므로 Fable 5 메인 모델은 어드바이저 없이 실행됨 |

Fable 5는 메인 모델로 작동하든 어드바이저로 작동하든 Claude Code v2.1.170 이상 및 Fable 5 접근 권한이 필요합니다.

어드바이저를 `opus`나 `sonnet`으로 지정하거나, 롤아웃을 통해 다시 제공되는 시점부터 `fable`로 지정할 수 있습니다. 이러한 별칭은 각 모델의 최신 버전으로 해석됩니다. `claude-opus-4-8`과 같은 전체 모델 ID를 전달할 수도 있습니다.

서브에이전트는 구성된 어드바이저를 상속받으며 자체 모델에 대해 동일한 페어링 검사를 적용합니다.

Claude Code는 요청을 보내기 전에 페어링의 유효성을 검사합니다:

* 어드바이저의 성능이 메인 모델보다 떨어지는 경우, 어드바이저는 메인 모델의 요청에 연결되지 않습니다. `/advisor` 명령 출력 및 알림에 이 사실이 표시됩니다. 자체 모델이 페어링 기준을 충족하는 서브에이전트는 여전히 어드바이저를 사용할 수 있습니다.
* 메인 모델이나 어드바이저가 Claude Code가 인식하지 못하는 모델인 경우 어드바이저가 연결되지 않습니다.

### 일반적인 모델 조합

허용된 조합은 모두 작동합니다. Fable 5를 어드바이저로 사용하는 조합은 Fable 5가 [어드바이저 옵션으로 돌아온](#어드바이저-활성화하기) 후에 적용됩니다. 이러한 조합은 비용과 성능 간의 균형을 다르게 맞춥니다:

| 조합 | 사용 시기 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Sonnet 메인 + Opus 어드바이저 | Sonnet이 일상적인 작업을 처리하고 계획, 모호한 실패, 완료 검사를 Opus로 에스컬레이션함 |
| Sonnet 메인 + Fable 어드바이저 | 전체 대화 동안 Fable 5를 실행하지 않고 결정 시점에 Fable 5 지침을 받음. v2.1.170 이상 및 Fable 5 접근 권한 필요 |
| Haiku 메인 + Opus 어드바이저 | 강력한 계획 능력을 갖춘 가장 저렴한 메인 모델 조합. Haiku 단독보다 비용이 높지만 메인 모델을 Sonnet이나 Opus로 바꾸는 것보다 낮음 |
| Opus 메인 + Opus 어드바이저 | 제2의 Opus가 첫 번째 Opus를 검토함. 비용보다 독립적인 검증이 더 중요한 고위험 작업에 유용함 |
| Fable 메인 + Fable 어드바이저 | Fable 5를 이용할 수 있을 때 가장 뛰어난 성능의 조합(v2.1.170+). Fable은 Opus 및 Sonnet보다 높은 등급이므로 Fable 메인 모델에 허용되는 유일한 어드바이저임 |
| Sonnet 메인 + Sonnet 어드바이저 | 일상적인 간과 사항을 잡아내기 위한 저비용의 제2의 의견 |

## Claude가 어드바이저에 자문을 구하는 시점

Claude는 언제 어드바이저를 호출할지 스스로 결정합니다. 접근 방식을 확정하기 전, 오류가 계속 반복될 때, 작업을 완료로 선언하기 전에 자문을 구하는 경향이 있지만, 그 타이밍은 규칙 기반이 아니라 모델에 의해 주도됩니다.

프롬프트에서 다른 도구를 요청하는 것과 동일하게 `consult the advisor before you continue`와 같이 자문을 요청할 수 있습니다. 어드바이저 호출 횟수를 제한하거나 강제하는 설정은 없습니다. 작업 도중 Claude가 더 자주 또는 덜 자주 자문을 구하도록 하려면 지침에 명시하세요.

## 세션 중 표시되는 내용

Claude가 어드바이저를 호출하면 호출이 진행되는 동안 트랜스크립트에 어드바이저 모델 이름과 함께 `Advising` 줄이 표시됩니다. 결과가 반환되면 어드바이저가 대화를 검토했음을 해당 줄이 확인합니다. `Ctrl+O`를 눌러 이를 확장하고 어드바이저의 전체 지침을 읽을 수 있습니다.

Claude는 일반적으로 어드바이저의 지침을 따르지만, 자체 증거가 특정 주장에 모순되는 경우 이에 적응합니다. 즉, 권장된 단계를 시도했을 때 실패하거나 파일 내용이 조언과 상충되는 경우 지침을 무조건 따르지 않고 모순을 드러냅니다.

어드바이저는 항상 전체 대화를 수신하며 Claude가 타이밍을 제어합니다. 더 많은 제어가 필요하거나 다른 구성을 원한다면 [서브에이전트 및 opusplan과의 비교](#관련-기능과의-비교)를 참조하세요.

## 비용

어드바이저가 호출될 때마다 대화 내용이 어드바이저 모델로 전송되므로 메인 모델 사용량 외에 어드바이저 모델의 요율로 토큰이 소비됩니다. API 청구 방식을 사용하는 경우 어드바이저 토큰은 어드바이저 모델의 입력 및 출력 요율로 청구됩니다. 구독 요금제에서는 어드바이저 사용량이 요금제의 사용량 한도에 차감됩니다.

Claude는 모든 턴이 아닌 결정 시점에 어드바이저를 호출하므로, 더 빠른 메인 모델에 더 강력한 어드바이저를 조합하는 것이 전체 대화 동안 더 강력한 모델을 실행하는 것보다 일반적으로 비용이 적게 듭니다. 어드바이저 사용량은 [`/usage`](/docs/en/costs#track-your-costs)에 표시되는 세션 합계에 포함됩니다.

API 응답에 어드바이저 토큰이 보고되는 방식은 Claude API 문서의 [사용량 및 청구](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool#usage-and-billing)를 참조하세요.

## 프롬프트 캐싱에 미치는 영향

세션 중간에 어드바이저를 활성화하거나 비활성화해도 메인 모델의 [프롬프트 캐시](/docs/en/prompt-caching)가 무효화되지 않습니다. [모델이나 effort 수준 변경](/docs/en/prompt-caching#actions-that-invalidate-the-cache)과 달리 `/advisor`를 전환해도 캐시된 접두사는 그대로 유지되며, 반환된 어드바이저 지침은 이후 턴에서 트랜스크립트의 일부로 캐시됩니다.

어드바이저 모델 자체의 대화 읽기는 캐시되지 않습니다. 각 어드바이저 호출은 호출 간 재사용 없이 전체 트랜스크립트를 새로 처리합니다.

## 요구사항

어드바이저 도구를 사용하려면 다음이 모두 필요합니다:

* **Anthropic API 전용**: 어드바이저는 서버에서 실행되는 도구입니다. Amazon Bedrock, AWS의 Claude Platform, Google Cloud's Agent Platform 또는 Microsoft Foundry에서는 사용할 수 없습니다. `ANTHROPIC_BASE_URL`로 구성된 [LLM 게이트웨이](/docs/en/llm-gateway)를 통한 사용 가능 여부는 게이트웨이가 요청을 손상 없이 Anthropic API로 전달하는지 여부에 따라 달라집니다.
* **지원되는 메인 모델**: Opus 4.6 이상, Sonnet 4.6 이상, 또는 Haiku 4.5. {/* min-version: 2.1.170 */}Claude Code v2.1.170 이상에서는 Fable 5도 자격이 주어지지만, Fable 5 메인은 [Fable 어드바이저만 허용](#어드바이저-모델-선택하기)하고 Fable은 [어드바이저로 제공되지 않으므로](#어드바이저-활성화하기) Fable 5 세션은 롤아웃을 통해 옵션으로 돌아올 때까지 어드바이저 없이 실행됩니다.

## 어드바이저 끄기

어드바이저 사용을 중지하고 저장된 `advisorModel`을 지우려면 `/advisor off`를 실행하거나 `/advisor` 선택기에서 **No advisor**를 선택하세요:

```
/advisor off
```

어드바이저 도구 자체를 completamente 비활성화하려면 `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1`을 설정하세요. `/advisor` 명령을 사용할 수 없게 되며 구성된 `advisorModel`은 무시됩니다. `--advisor` 플래그는 허용되지만 아무런 효과가 없으므로 이를 전달하는 기존 스크립트는 오류 없이 계속 동작합니다. [환경 변수](/docs/en/env-vars)를 참조하세요.

## 관련 기능과의 비교

어드바이저는 모델의 강점을 결합하는 여러 방법 중 하나입니다. 두 번째 모델을 참여시키고자 하는 시점에 따라 선택하세요.

| 접근 방식 | 더 강력한 모델이 실행되는 시점 | 시작 방식 |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| 어드바이저 도구 | 작업 중간의 결정 시점 | 지침이 필요할 때 Claude가 호출함 |
| [`opusplan`](/docs/en/model-config#opusplan-model-setting) | [`availableModels`에서 허용 시](/docs/en/model-config#restrict-model-selection) 플랜 모드 동안 실행된 후 실행을 위해 Sonnet으로 전환됨 | 사용자가 플랜 모드에 진입함 |
| `model`이 설정된 [서브에이전트](/docs/en/sub-agents#choose-a-model) | 위임된 하위 작업 전체 동안 실행됨 | Claude가 위임하거나 사용자가 서브에이전트를 호출함 |
| [`/model`](/docs/en/model-config#setting-your-model) | 이후 모든 턴 동안 실행됨 | 사용자가 모델을 전환함 |
