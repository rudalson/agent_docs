    <div>로그인 화면의 가이드 기반 <a href="/docs/docs/en/amazon-bedrock">Amazon Bedrock</a> 및 <a href="/docs/docs/en/google-vertex-ai">Google Cloud's Agent Platform</a> 설정 마법사: 단계별 인증, 리전, 자격 증명 검사 및 모델 고정을 위해 "3rd-party platform" 선택</div>
    <div><code>/agents</code>가 탭 레이아웃을 받음: Running 탭은 <code>● N running</code> 개수와 함께 라이브 서브에이전트를 보여주며, Library 탭에는 Run agent 및 View running instance 작업이 포함됨</div>
    <div>API 키, Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, Team, Enterprise 사용자의 기본 노력 수준이 이제 <code>high</code>임 (<code>/effort</code>로 제어)</div>
    <div>구독 사용자에게 <code>/cost</code>가 모델별 및 캐시 적중 분석을 보여줌</div>
    <div><code>/release-notes</code>가 이제 대화형 버전 선택기임</div>
    <div>상태 표시줄: 새 <code>refreshInterval</code> 설정이 N초마다 명령을 다시 실행함, JSON 입력의 <code>workspace.git\_worktree</code></div>
    <div><code>CLAUDE\_CODE\_PERFORCE\_MODE</code>: Edit/Write가 묵묵히 덮어쓰는 대신 <code>p4 edit</code> 힌트와 함께 읽기 전용 파일에서 실패함</div>
    <div>OS CA 인증서 저장소가 이제 기본적으로 신뢰되므로 기업 TLS 프록시가 추가 설정 없이 작동함 (옵트아웃하려면 <code>CLAUDE\_CODE\_CERT\_STORE=bundled</code>)</div>
    <div>Mantle로 구동되는 Amazon Bedrock: <code>CLAUDE\_CODE\_USE\_MANTLE=1</code> 설정</div>
    <div>강화된 Bash 도구 권한: 백슬래시 이스케이프 플래그, 환경 변수 접두사, <code>/dev/tcp</code> 리디렉션, 복합 명령이 이제 올바르게 프롬프트를 표시함</div>
    <div><code>UserPromptSubmit</code> 훅이 <code>hookSpecificOutput.sessionTitle</code>을 통해 세션 제목을 설정할 수 있음</div>
  </div>
