  <p className="digest-feature-lede">거부 및 권한 요청 규칙은 이제 <code>Tool(param:value)</code> 구문을 사용하여 도구의 입력 매개변수를 일치시킬 수 있습니다. 예를 들어 <code>Agent(model:opus)</code>는 Opus 모델 계층을 요청하는 서브에이전트 생성을 일치시킵니다. 값에는 와일드카드로 `*`를 허용하므로 `Agent(isolation:*)`는 명시적 격리 값 전체를 일치시킵니다.</p>

  <p className="digest-feature-try"><code>settings.json</code>의 거부 목록에 매개변수 규칙을 추가하세요:</p>

  ```json .claude/settings.json {3} theme={null}
  {
    "permissions": {
      "deny": ["Agent(model:opus)"]
    }
  }
  ```

  <p className="digest-feature-try">프롬프트에서 <code>thinking</code> 설정을 변경:</p>

  ```text Claude Code theme={null}
  > /config thinking=false
  ```

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div>자동 모드는 이제 로컬 작업을 삭제하라고 요청하지 않은 경우 파괴적인 git 명령(`git reset --hard`, `git clean -fd`, `git stash drop`)을 차단하고, 특정 스택을 요청하지 않는 한 <code>terraform destroy</code>를 차단합니다</div>
    <div>새로운 <code>attribution.sessionUrl</code> 설정을 <code>false</code>로 설정하면 웹 및 Remote Control 세션의 커밋 및 PR에서 claude.ai 세션 링크를 생략할 수 있습니다</div>
    <div><code>/config</code> 인터페이스에서 Enter와 Space 모두 선택한 설정을 변경하며, Esc는 이제 원래대로 되돌리는 대신 저장하고 닫습니다</div>
    <div>새로운 <code>sandbox.allowAppleEvents</code> 옵트인 설정을 사용하면 macOS의 샌드박스 처리된 명령이 Apple Events를 보낼 수 있습니다</div>
    <div>머신 앞에 있는 동안 모바일 푸시 알림을 억제하려면 <code>CLAUDE\_CLIENT\_PRESENCE\_FILE</code>을 마커 파일로 지정하세요</div>
    <div>긴 단락은 이제 첫 번째 줄 바꿈을 기다리지 않고 한 줄씩 스트리밍됩니다</div>
    <div>사고(thinking) 도중 API 연결이 끊기면 "Connection closed while thinking"을 표시하는 대신 자동으로 재시도합니다</div>
    <div><code>CLAUDE\_CODE\_EXPERIMENTAL\_AGENT\_TEAMS=1</code>이 설정되면 모든 세션에 암시적 팀이 하나씩 있으므로 Agent 도구의 <code>name</code> 매개변수로 팀원을 직접 생성할 수 있습니다</div>
    <div>중첩된 <code>.claude/skills</code> 디렉토리의 스킬은 해당 위치에서 파일을 작업할 때 로드됩니다. 이름 충돌 시 중첩된 스킬은 `<dir>:<name>`으로 표시되어 둘 다 사용할 수 있도록 유지됩니다</div>
    <div>커스텀 <code>ANTHROPIC\_BASE\_URL</code> 및 Microsoft Foundry에서 프롬프트 캐싱을 읽지 못하던 문제를 해결했습니다</div>
    <div>네트워크 드라이브 및 클라우드 동기화 폴더에서 Write 및 Edit가 0바이트 또는 잘린 파일을 생성하던 문제를 해결했습니다</div>
  </div>
</div>
