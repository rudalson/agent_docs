# 19주차 · 2026년 5월 4일–8일

  <p className="digest-feature-try">URL에서 직접 플러그인 로드:</p>

  ```bash terminal theme={null}
  claude --plugin-url https://example.com/my-plugin.zip
  ```

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div>새로운 <code>worktree.baseRef</code> 설정(<code>fresh</code> | <code>head</code>)은 <code>--worktree</code>, <code>EnterWorktree</code> 도구 및 에이전트 격리 워크트리가 원격 기본 브랜치에서 분기할지, 아니면 로컬 <code>HEAD</code>에서 분기할지를 제어합니다. 기본값인 <code>fresh</code>는 푸시되지 않은 커밋이 새 워크트리에 포함되지 않도록 유지합니다</div>
    <div>새로운 <code>settings.autoMode.hard\_deny</code> 규칙은 자동 모드에서 하위 허용 예외와 상관없이 일치하는 작업을 무조건 차단합니다. 이는 더 넓은 허용 규칙이 적용되는 경우에도 자동으로 실행되어서는 안 되는 작업에 사용됩니다</div>
    <div>훅은 이제 `effort.level` JSON 입력 필드 및 `$CLAUDE_EFFORT` 환경 변수를 통해 활성 노력 수준(effort level)을 전달받으며, Bash 도구 명령은 <code>\$CLAUDE\_EFFORT</code>를 읽을 수 있습니다</div>
    <div><code>CLAUDE\_CODE\_DISABLE\_ALTERNATE\_SCREEN=1</code>은 전체 화면 대체 화면 렌더러를 사용하지 않고 대화를 터미널의 기본 스크롤백으로 유지합니다</div>
    <div><code>CLAUDE\_CODE\_PACKAGE\_MANAGER\_AUTO\_UPDATE</code>를 사용하면 Homebrew 또는 WinGet 설치 시 백그라운드에서 업그레이드를 실행하고 재시작을 요청할 수 있습니다</div>
    <div><code>CLAUDE\_CODE\_SESSION\_ID</code>가 이제 Bash 도구 하위 프로세스 환경에 포함되어 훅으로 전달되는 <code>session\_id</code>와 일치합니다</div>
    <div><code>/mcp</code>는 이제 연결된 서버의 도구 수를 보여주고 도구 수가 0개인 상태로 연결된 서버에 플래그를 표시합니다</div>
    <div><code>--channels</code>는 이제 콘솔(API 키) 인증에서 작동합니다</div>
    <div>Bash, 훅, MCP, LSP와 같은 하위 프로세스는 더 이상 <code>OTEL\_\*</code> 환경 변수를 상속받지 않으므로, Bash 도구를 통해 실행되는 OTEL 적용 앱이 CLI 자체의 OTLP 엔드포인트를 사용하지 않게 됩니다</div>
    <div>서브에이전트 진행 상황 요약이 이제 프롬프트 캐시에 적중하여 <code>cache\_creation</code> 토큰 비용을 약 3배 절감합니다</div>
    <div>여러 OAuth 및 자격 증명 신뢰성 수정: 병렬 세션이 리프레시 토큰 경합 후 401 오류로 교착 상태에 빠지지 않으며, 여러 서버가 동시에 새로 고쳐질 때 MCP OAuth 리프레시 토큰이 더 이상 손실되지 않으며, 동시 자격 증명 쓰기로 인한 드문 로그인 루프가 해결되었습니다</div>
    <div>새로운 <code>parentSettingsBehavior</code> 관리자 키를 통해 관리자는 SDK <code>managedSettings</code>를 정책 병합에 옵트인시킬 수 있습니다</div>
  </div>
