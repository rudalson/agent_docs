  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/interactive-mode#vim-editor-mode">Vim 비주얼 모드</a>: 프롬프트 입력창에서 <code>v</code>를 눌러 문자 선택, <code>V</code>를 눌러 줄 선택을 할 수 있으며 연산자 및 시각적 피드백이 제공됩니다</div>
    <div>훅은 이제 <a href="/docs/docs/en/hooks#mcp-tool-hook-fields"><code>type: "mcp\_tool"</code></a>을 통해 MCP 도구를 직접 호출할 수 있으므로, 훅이 프로세스를 생성하지 않고도 이미 연결된 서버에 액세스할 수 있습니다</div>
    <div><code>/cost</code> 및 <code>/stats</code>가 <a href="/docs/docs/en/commands"><code>/usage</code></a>로 통합되었습니다. 기존 이름은 해당 탭을 여는 타이핑 단축키로 여전히 작동합니다</div>
    <div><code>/config</code> 변경 사항(테마, 에디터 모드, 자세한 출력(verbose) 등)은 이제 <code>\~/.claude/settings.json</code>에 영구 저장되며 다른 <a href="/docs/docs/en/settings">설정</a>과 동일한 프로젝트/로컬/정책 우선순위를 따릅니다</div>
    <div><a href="/docs/docs/en/sub-agents#fork-the-current-conversation">포크된 서브에이전트</a>는 <code>CLAUDE\_CODE\_FORK\_SUBAGENT=1</code>을 사용해 외부 빌드에서 활성화할 수 있습니다. 포크된 서브에이전트는 새로 시작하는 대신 전체 대화 컨텍스트를 상속받습니다</div>
    <div>Opus 4.6 및 Sonnet 4.6의 Pro 및 Max 구독자를 위한 기본 <a href="/docs/docs/en/model-config#adjust-effort-level">노력 수준(effort level)</a>이 이제 <code>high</code>가 되었습니다(기존에는 <code>medium</code>)</div>
    <div>기본 macOS 및 Linux 빌드는 <code>Glob</code> 및 <code>Grep</code> 도구를 Bash를 통해 사용할 수 있는 내장된 <code>bfs</code> 및 <code>ugrep</code>으로 대체하여 별도의 도구 라운드트립 없이 더 빠른 검색을 지원합니다</div>
    <div><code>--from-pr</code>은 이제 github.com 외에도 GitLab merge request, Bitbucket pull request, GitHub Enterprise PR URL을 지원합니다</div>
    <div>자동 모드(Auto mode): <a href="/docs/docs/en/auto-mode-config"><code>autoMode.allow</code>, <code>soft\_deny</code> 또는 <code>environment</code></a>에 <code>"\$defaults"</code>를 포함하여 내장 목록을 대체하는 대신 내장 목록과 함께 커스텀 규칙을 추가할 수 있습니다</div>
    <div>새로운 <a href="/docs/docs/en/plugin-dependencies#tag-plugin-releases-for-version-resolution"><code>claude plugin tag</code></a> 명령은 버전 검증을 통해 플러그인의 릴리스 git 태그를 생성합니다</div>
    <div>Opus 4.7 세션은 이제 모델의 기본 1M 컨텍스트 윈도우에 대해 계산되어 과다 표시되던 <code>/context</code> 백분율과 조기 자동 압축 문제를 해결합니다</div>
    <div>대규모 세션에서 <code>/resume</code> 속도가 최대 67% 빨라졌으며, 다시 읽기전에 오래되고 큰 세션을 요약하는 옵션을 제공합니다</div>
