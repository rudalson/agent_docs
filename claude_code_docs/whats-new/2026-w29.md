    <span className="digest-feature-pill">CLI</span>

  <p className="digest-feature-lede">스크린 리더 모드는 시각적 터미널 인터페이스를 플레인 리니어 텍스트(선형 텍스트)로 대체합니다. 상자, 스피너, 인플레이스 다시 그리기 대신 VoiceOver 또는 NVDA와 같은 스크린 리더가 순서대로 읽을 수 있도록 라벨이 지정된 줄을 Claude Code가 출력하므로 권한을 승인하고 출력을 처음부터 끝까지 검토할 수 있습니다. 플래그를 사용하여 세션별로, <code>CLAUDE\_AX\_SCREEN\_READER</code> 환경 변수를 사용하여 쉘별로, 또는 <code>axScreenReader</code> 설정을 사용하여 전역으로 켤 수 있습니다.</p>

  <p className="digest-feature-try">스크린 리더 모드로 세션 시작:</p>

  ```bash terminal theme={null}
  claude --ax-screen-reader
  ```

  <a className="digest-feature-link" href="/docs/docs/en/accessibility#turn-on-screen-reader-mode">스크린 리더 모드 켜기</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><code>/fork</code>는 이제 계속 작업하는 동안 자체 행이 <code>claude agents</code>에 있는 새 백그라운드 세션으로 대화를 복사합니다. 이전에 실행되던 세션 내 포크된 서브에이전트는 이제 <code>/subtask</code>가 되었습니다</div>
    <div><a href="/docs/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">자동 모드</a>는 이제 Amazon Bedrock, Google Cloud's Agent Platform 및 Microsoft Foundry에서 <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE</code> 옵트인이 더 이상 필요하지 않습니다. 관리자는 <code>disableAutoMode</code>로 끌 수 있습니다</div>
    <div>2분 이상 실행되는 MCP 도구 호출은 세션의 사용 가능 상태를 유지하기 위해 자동으로 백그라운드로 이동합니다. <code>CLAUDE\_CODE\_MCP\_AUTO\_BACKGROUND\_MS</code>로 임계값을 조정하거나 비활성화하세요</div>
    <div>새로운 <code>claude auto-mode reset</code>은 기본 자동 모드 구성을 복원하며, `--yes`는 확인 프롬프트를 건너뜁니다</div>
    <div>새로운 <a href="/docs/docs/en/corporate-launcher">기업용 런처(corporate launcher)</a> 지원: <code>CLAUDE\_CODE\_PROCESS\_WRAPPER</code> 또는 <code>processWrapper</code> 설정은 필수 래퍼 실행 파일을 통해 백그라운드 서비스 및 에이전트 뷰 세션과 같이 Claude Code가 자체 바이너리에서 시작하는 프로세스를 실행합니다</div>
    <div><code>vimInsertModeRemaps</code> 설정은 vim 모드에서 <code>jj</code>와 같은 두 키 입력 모드 시퀀스를 Escape에 매핑합니다</div>
    <div>`--forward-subagent-text` 및 <code>CLAUDE\_CODE\_FORWARD\_SUBAGENT\_TEXT</code>는 <a href="/docs/docs/en/headless">stream-json 출력</a>에 서브에이전트 텍스트 및 사고(thinking) 블록을 포함합니다</div>
    <div>세션 전체 한도로 제어 불능 루프를 방지합니다: WebSearch 호출 및 서브에이전트 생성의 기본값은 각각 200개이며, <code>CLAUDE\_CODE\_MAX\_WEB\_SEARCHES\_PER\_SESSION</code> 및 <code>CLAUDE\_CODE\_MAX\_SUBAGENTS\_PER\_SESSION</code>으로 조정 가능합니다</div>
    <div>"Always allow"(항상 허용) 권한 규칙이 리포지토리 루트에 저장되므로 git 워크트리에서 부여된 승인이 세션 및 워크트리 전반에 영구적으로 유지됩니다</div>
    <div>Amazon Bedrock, Google Cloud's Agent Platform 및 AWS의 Claude Platform은 이제 기본값이 Claude Opus 4.8로 설정됩니다</div>
    <div>접힌 도구 요약 줄에 실시간 경과 시간 카운터가 표시되어 장시간 실행되는 도구 호출이 멈춘 것처럼 보이지 않고 시각적으로 진행됨을 보여줍니다</div>
