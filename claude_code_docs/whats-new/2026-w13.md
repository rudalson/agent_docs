<div className="digest-feature">

    <span className="digest-feature-pill">리서치 프리뷰</span>
  </div>

  <p className="digest-feature-lede">Auto 모드는 권한 프롬프트를 분류기(classifier)에 전달합니다. 안전한 편집과 명령은 사용자를 방해하지 않고 실행되며, 파괴적이거나 의심스러운 모든 항목은 차단되고 표출됩니다. 이는 모든 파일 쓰기를 승인하는 것과 <code>--dangerously-skip-permissions</code>로 실행하는 것 사이의 중용입니다.</p>

  <Frame>
    <img src="https://mintcdn.com/claude-code/CfffsX01JHFnIKvD/images/whats-new/auto-mode.png?fit=max&auto=format&n=CfffsX01JHFnIKvD&q=85&s=367c9e9d4ba5bc57ec4b935154bf1fbb" alt="Claude Code prompt footer showing 'auto mode on (shift+tab to cycle)' indicator in yellow" width="2400" height="691" data-path="images/whats-new/auto-mode.png" />
  </Frame>

  <p className="digest-feature-try">Shift+Tab으로 auto로 전환하거나 기본값으로 설정하세요:</p>

  ```json ~/.claude/settings.json {3} theme={null}
  {
    "permissions": {
      "defaultMode": "auto"
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/en/permission-modes">권한 모드 가이드</a>
</div>

  <p className="digest-feature-lede">트랜스크립트 모드에서 <code>/</code>를 눌러 대화를 검색하세요. <code>n</code>과 <code>N</code>으로 일치 항목을 이동합니다. 마침내 400개 메시지 전에 Claude가 실행했던 그 하나의 Bash 명령을 찾는 방법이 생겼습니다.</p>

  <p className="digest-feature-try">트랜스크립트 모드를 열고 검색하세요:</p>

  ```text Claude Code theme={null}
  Ctrl+O    # 트랜스크립트 열기
  /migrate  # "migrate" 검색
  n         # 다음 일치 항목
  N         # 이전 일치 항목
  ```

  <a className="digest-feature-link" href="/docs/docs/en/fullscreen#search-and-review-the-conversation">전체 화면 가이드</a>

    <span className="digest-feature-pill">프리뷰</span>

  <p className="digest-feature-lede">Windows는 Bash와 함께 네이티브 PowerShell 도구를 받습니다. Claude는 모든 것을 Git Bash를 통해 변환하지 않고도 cmdlet을 실행하고, 객체를 파이프하며, Windows 네이티브 경로로 작업할 수 있습니다.</p>

  <p className="digest-feature-try">설정에서 옵트인하세요:</p>

  ```json .claude/settings.json {3} theme={null}
  {
    "env": {
      "CLAUDE_CODE_USE_POWERSHELL_TOOL": "1"
    }
  }
  ```

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">조건부 훅 (Conditional hooks)</span>
    <span className="digest-feature-pill">v2.1.85</span>
  </div>

  <p className="digest-feature-lede">이제 훅이 권한 규칙 구문을 사용하여 <code>if</code> 필드를 선언할 수 있습니다. 사전 커밋 검사가 모든 bash 호출 대신 <code>Bash(git commit \*)</code>에 대해서만 스폰되어 바쁜 세션의 프로세스 오버헤드를 줄입니다.</p>

  <p className="digest-feature-try">git 커밋에 대해서만 훅의 범위를 지정하세요:</p>

  ```json .claude/settings.json {5} theme={null}
  {
    "hooks": {
      "PreToolUse": [{
        "hooks": [{
          "if": "Bash(git commit *)",
          "type": "command",
          "command": ".claude/hooks/lint-staged.sh"
        }]
      }]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/en/hooks">훅 참조 문서</a>
</div>
