# 16주차 · 2026년 4월 13일–17일

> 새로운 xhigh 노력 수준(effort level)이 적용된 Claude Opus 4.7, 웹상 Claude Code의 루틴(Routines), Claude가 필요한 경우 전화로 핑을 보내는 모바일 푸시 알림, 사용 한도를 이끄는 요소를 보여주는 /usage 분석, 번들로 제공되던 JavaScript를 대체하는 네이티브 바이너리.

  <p className="digest-feature-lede">Anthropic의 가장 강력한 코딩 모델이 이제 Max 및 Team Premium의 기본 모델이 되었으며, <code>/model</code>을 통해 다른 곳에서도 모두 사용할 수 있습니다. <code>high</code>와 <code>max</code> 사이에 위치한 새로운 <code>xhigh</code> 노력 수준(effort level)이 추가되었습니다: 대부분의 코딩 및 에이전트 작업에 최선의 결과를 제공하며, 4.7로 처음 전환할 때 기본값으로 적용됩니다. <code>/effort</code>를 인자 없이 호출하면 대화형 화살표 키 슬라이더가 열리므로 수준 이름을 기억하지 않고도 속도 대비 지능을 조정할 수 있습니다.</p>

  <p className="digest-feature-try">모델과 노력 수준을 한 번에 전환:</p>

  ```text Claude Code theme={null}
  > /model opus
  > /effort xhigh
  ```

  <p className="digest-feature-try">업그레이드하고 실행 중인 버전을 확인하세요:</p>

  <div className="digest-wins-grid">
    <div>새로운 <a href="/docs/docs/en/ultrareview"><code>/ultrareview</code></a>: 병렬 멀티 에이전트 분석 및 적대적 비평 패스(adversarial critique pass)를 활용한 클라우드에서의 종합적인 코드 리뷰. 인자 없이 실행하여 현재 브랜치를 리뷰하거나, 특정 PR에 대해 <code>/ultrareview \<PR#></code>를 실행하세요</div>
    <div>Max 구독자는 Opus 4.7에서 <a href="/docs/docs/en/permission-modes#eliminate-prompts-with-auto-mode">자동 모드(Auto mode)</a>를 사용할 수 있으며, <code>--enable-auto-mode</code> 플래그가 더 이상 필요하지 않습니다</div>
    <div><a href="/docs/docs/en/interactive-mode#session-recap">세션 요약(Session recap)</a>은 자리를 비운 동안 발생한 일에 대한 한 줄 요약을 보여줍니다. 필요할 때 <code>/recap</code>을 실행하거나 <code>/config</code>에서 끌 수 있습니다</div>
    <div>새로운 <code>/tui</code> 명령 및 <code>tui</code> 설정으로 대화 도중에 클래식 렌더링과 깜빡임 없는(flicker-free) 렌더링 간을 전환할 수 있으며, 포커스 뷰는 <code>Ctrl+O</code>에서 자체 <code>/focus</code> 명령으로 이동했습니다</div>
    <div>플러그인은 세션 시작 시 또는 스킬 호출 시 자동 활성화되는 최상위 <code>monitors</code> 매니페스트 키를 통해 백그라운드 감시자(watcher)를 전달할 수 있습니다</div>
    <div><code>/theme</code>의 "Auto (match terminal)" 옵션은 터미널의 다크/라이트 모드를 따릅니다</div>
    <div><code>/fewer-permission-prompts</code>는 트랜스크립트에서 공통 읽기 전용 Bash 및 MCP 호출을 스캔하고 <code>.claude/settings.json</code>에 대한 허용 목록을 제안합니다</div>
    <div>Claude는 이제 Skill 도구를 통해 <code>/init</code>, <code>/review</code>, <code>/security-review</code>와 같은 내장 명령을 검색하고 실행할 수 있습니다</div>
    <div><code>PreCompact</code> 훅은 코드 2로 종료하거나 <code>{"{"}"decision":"block"{"}"}</code>을 반환하여 압축(compaction)을 차단할 수 있습니다</div>
    <div><code>ENABLE\_PROMPT\_CACHING\_1H</code>는 API 키, Amazon Bedrock, Google Cloud의 Agent Platform 및 Microsoft Foundry 사용자가 1시간 프롬프트 캐시 TTL을 옵트인할 수 있도록 합니다</div>
    <div><code>sandbox.network.deniedDomains</code> 설정은 더 넓은 <code>allowedDomains</code> 와일드카드에서 특정 도메인을 제외합니다</div>
    <div><code>/undo</code>는 이제 <code>/rewind</code>의 별칭이며, <code>/proactive</code>는 <code>/loop</code>의 별칭입니다</div>
    <div>강화된 Bash 권한: 거부 규칙은 이제 <code>env</code>/<code>sudo</code>/<code>watch</code> 래퍼를 통해 일치하며, <code>Bash(find:\*)</code> 허용 규칙은 더 이상 <code>-exec</code> 또는 <code>-delete</code>를 자동 승인하지 않습니다</div>
