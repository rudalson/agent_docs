# 21주차 · 2026년 5월 18일–22일

> Pro 플랜 및 Sonnet 4.6에서 자동 모드 사용, /usage에서 플랜 한도를 이끄는 스킬, 서브에이전트 및 MCP 서버 확인, 새로운 /code-review 명령으로 변경 사항 리뷰.

    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">자동 모드가 이제 Pro 플랜에서 제공되며 Opus와 함께 Sonnet 4.6을 지원합니다. 권한 프롬프트가 백그라운드 안전성 검사로 대체되어 무난한 작업은 방해 없이 실행되고, 파괴적이거나 의심스러운 작업은 차단되어 노출됩니다.</p>

  <p className="digest-feature-try">Claude Code를 업데이트한 다음 Shift+Tab으로 모드를 전환하세요. 계정이 요구 사항을 충족하면 전환 주기에 자동 모드가 나타납니다:</p>

  ```bash terminal theme={null}
  claude update
  ```

  <p className="digest-feature-try">명령은 새 버전 번호와 함께 <code>Successfully updated</code>를 출력하거나 업데이트가 필요하지 않은 경우 <code>Claude Code is up to date</code>를 출력합니다. 자동 모드가 활성화되면 프롬프트 푸터에 <code>auto mode on</code>이 표시됩니다.</p>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/costs#track-your-costs"><code>/usage</code></a>는 이제 사용 한도를 이끄는 요소를 카테고리별 내역으로 보여주며, 최근 사용량을 스킬, 서브에이전트, 플러그인 및 개별 MCP 서버별로 구분합니다</div>
    <div>"Extra usage"(추가 사용량)가 CLI 전반에서 "usage credits"(사용 크레딧)로 이름이 변경되었으며, <code>/extra-usage</code>는 이제 <code>/usage-credits</code>가 되었습니다. 이전 이름도 여전히 작동합니다. 이 명령은 <code>/login</code>을 통해 claude.ai 구독에 로그인해야 하며 API 키 인증에서는 사용할 수 없습니다.</div>
    <div>새로운 <a href="/docs/docs/en/code-review"><code>/code-review</code></a> 명령은 <code>/code-review high</code>와 같이 선택한 노력 수준(effort level)에서 정성적 버그를 보고하며, <code>--comment</code>는 탐색 결과를 인라인 GitHub PR 댓글로 게시합니다. <code>/simplify</code>는 정리 전용 리뷰로 별도 유지됩니다.</div>
    <div>백그라운드 세션이 <code>bg</code>로 표시되어 대화형 세션과 함께 <code>/resume</code>에 나타나며, <code>claude agents</code>에서 <code>Ctrl+T</code>로 고정된 세션은 유휴 상태에서도 유지됩니다</div>
    <div><code>claude agents --json</code>은 상태 표시줄 및 세션 선택기와 같은 스크립팅을 위해 실시간 세션을 JSON으로 나열합니다</div>
    <div>PowerShell 도구가 이제 Windows의 Amazon Bedrock, Google Cloud's Agent Platform 및 Microsoft Foundry 사용자에 대해 기본 활성화됩니다. <code>CLAUDE\_CODE\_USE\_POWERSHELL\_TOOL=0</code>으로 옵트아웃하세요</div>
    <div><code>claude plugin disable</code>은 다른 활성화된 플러그인이 대상에 의존하는 경우 작업을 거부하며, <code>claude plugin enable</code>은 전이적 의존성을 강제 활성화합니다</div>
    <div><code>/plugin</code> 마켓플레이스 탐색 창에 예상 컨텍스트 비용이 표시되며, 검색 및 탐색 화면에는 설치 전에 플러그인의 명령, 에이전트, 스킬, 훅, MCP/LSP 서버가 나열됩니다</div>
    <div>새로운 <code>worktree.bgIsolation: "none"</code> 설정은 워크트리를 적용하기 어려운 리포지토리를 위해 백그라운드 세션이 <code>EnterWorktree</code> 없이 작업 복사본을 직접 편집할 수 있도록 합니다</div>
    <div>마크다운 출력 시 GFM 작업 목록 체크박스를 렌더링하고, <code>/diff</code> 세부 정보 뷰는 키보드로 스크롤할 수 있습니다</div>
    <div>상태 줄 JSON 입력에는 이제 감지된 경우 GitHub 리포지토리 및 PR 정보가 포함됩니다</div>
    <div>기업용(Enterprise): <code>allowAllClaudeAiMcps</code> 관리형 설정은 <code>managed-mcp.json</code>과 함께 claude.ai 클라우드 MCP 커넥터를 로드합니다</div>
  </div>
</div>
