  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code>에서 쉘 명령 앞에 <code>!</code>를 붙여 연결하거나 분리할 수 있는 백그라운드 작업으로 실행할 수 있습니다. <code>claude --bg --exec 'pytest -x'</code>로도 사용할 수 있습니다</div>
    <div><code>.claude/skills</code> 디렉토리의 플러그인은 이제 마켓플레이스 없이도 자동으로 로드되며, <code>claude plugin init \<name></code>은 새 플러그인을 스캐폴딩합니다</div>
    <div>새로운 <code>/reload-skills</code> 명령은 재시작 없이 스킬 디렉토리를 다시 스캔하며, <code>SessionStart</code> 훅은 <code>reloadSkills: true</code>를 반환하여 설치한 스킬을 동일한 세션에서 사용할 수 있도록 합니다</div>
    <div>스킬 및 명령은 프론트매터(frontmatter)에서 <code>disallowed-tools</code>를 설정하여 스킬이 활성화된 동안 모델에서 도구를 제거할 수 있습니다</div>
    <div>새로운 <code>MessageDisplay</code> 훅 이벤트를 통해 훅은 어시스턴트 메시지 텍스트가 표시될 때 변형하거나 숨길 수 있습니다</div>
    <div>Claude Code는 이제 기본 모델을 찾을 수 없을 때 매 요청마다 실패하는 대신 세션의 남은 시간 동안 구성된 <code>--fallback-model</code>로 전환합니다</div>
    <div>플러그인은 <code>plugin.json</code> 또는 마켓플레이스 항목에서 <code>defaultEnabled: false</code>를 선언하여 사용자가 활성화할 때까지 켜지지 않은 상태로 설치할 수 있습니다</div>
    <div>Vim 모드: NORMAL 모드에서 <code>/</code>를 누르면 Bash 및 Zsh vi-mode와 동일하게 역방향 기록 검색이 열립니다</div>
    <div>스트리밍 도구 실행이 이제 원격 측정(telemetry)이 비활성화된 상태 및 Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry를 포함하여 항상 활성화됩니다</div>
    <div>에이전트 뷰를 여는 <code>←←</code> 키가 이제 Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry 및 원격 측정이 비활성화된 상태에서도 작동합니다</div>
    <div>Chrome의 Claude: <code>/chrome</code> → "Select browser…"를 통해 또는 여러 브라우저가 연결된 상태에서 브라우저 작업이 실행될 때 대화 내에서 사용할 연결된 브라우저를 선택하세요</div>
    <div><code>claude mcp list</code> 및 <code>claude mcp get</code>은 출력이 파이프될 때 자동 승인 및 연결 대신 승인되지 않은 <code>.mcp.json</code> 서버를 승인 대기 중으로 표시합니다</div>
