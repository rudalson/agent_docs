# 20주차 · 2026년 5월 11일–15일

> 에이전트 뷰를 사용하여 단일 화면에서 모든 Claude Code 세션을 관리하고, 조건이 충족될 때까지 Claude가 목표를 향해 계속 작동하도록 설정하며, Opus 4.7에서 패스트 모드(fast mode)를 기본적으로 실행합니다.

  <p className="digest-feature-lede"><code>/fast</code>는 이제 Opus 4.6 대신 Opus 4.7에서 기본적으로 실행됩니다. 패스트 모드는 초고속 Opus 구성입니다: 더 높은 토큰당 비용으로 동일한 모델 품질을 약 2.5배 속도로 제공하며, 빠른 반복 작업 및 실시간 디버깅에 유용합니다. 가격은 Opus 4.6 패스트 모드와 동일한 MTok당 \$30/\$150로 고정되어 있습니다. 패스트 모드를 Opus 4.6에 고정하려면 <code>CLAUDE\_CODE\_OPUS\_4\_6\_FAST\_MODE\_OVERRIDE=1</code>을 설정하세요.</p>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><code>claude agents</code>에 디스패치 플래그(<code>--add-dir</code>, <code>--settings</code>, <code>--mcp-config</code>, <code>--plugin-dir</code>, <code>--permission-mode</code>, <code>--model</code>, <code>--effort</code>, <code>--dangerously-skip-permissions</code>)가 추가되어 백그라운드 세션을 구성할 수 있으며, <code>claude agents --cwd \<path></code>로 세션 목록의 범위를 특정 디렉토리로 제한할 수 있습니다</div>
    <div>새로운 훅 <code>args: string\[]</code> 실행 형태는 쉘 없이 명령을 직접 실행하므로 경로 자리표시자에 따옴표를 넣을 필요가 없습니다</div>
    <div><code>PostToolUse</code> 훅용 새로운 <code>continueOnBlock</code> 구성 옵션은 훅의 거부 사유를 Claude에게 다시 제공하고 턴을 종료하는 대신 계속 진행하도록 합니다</div>
    <div>훅 JSON 출력의 새로운 <code>terminalSequence</code> 필드를 통해 훅은 제어 터미널 없이도 데스크톱 알림, 창 제목 및 벨을 내보낼 수 있습니다</div>
    <div>되감기(Rewind) 메뉴에 최근 턴을 유지하면서 이전 컨텍스트를 압축하는 "Summarize up to here"(여기까지 요약)가 추가되었습니다</div>
    <div><code>ANTHROPIC\_API\_KEY</code>, <code>apiKeyHelper</code> 또는 <code>ANTHROPIC\_AUTH\_TOKEN</code>이 설정되어 있으면 Claude.ai 로그인과 병행하더라도 Remote Control, <code>/schedule</code>, Claude.ai MCP 커넥터 및 알림 기본 설정이 비활성화됩니다. 이 기능을 사용하려면 API 키 설정을 해제하세요</div>
    <div>MCP stdio 서버는 이제 훅과 동일하게 환경에서 <code>CLAUDE\_PROJECT\_DIR</code>을 받으며, 플러그인 구성은 명령에서 <code>\${"{"}CLAUDE\_PROJECT\_DIR{"}"}</code>를 참조할 수 있습니다</div>
    <div><code>claude plugin details \<name></code>은 플러그인의 구성 요소 인벤토리 및 예상 세션당 토큰 비용을 보여주며, <code>/plugin</code> 세부 정보 창에도 이제 플러그인이 제공하는 LSP 서버가 나열됩니다</div>
    <div>하위 디렉토리 <code>skills/</code>가 없고 루트 수준의 <code>SKILL.md</code>만 있는 플러그인은 이제 스킬로 제공됩니다</div>
    <div><code>/feedback</code>에는 현재 세션 이상에 걸친 문제의 경우 지난 24시간 또는 7일간의 최근 세션을 포함할 수 있습니다</div>
    <div>Agent 도구 <code>subagent\_type</code>은 이제 대소문자 및 구분 기호를 구분하지 않으므로 <code>"Code Reviewer"</code>는 <code>code-reviewer</code>로 확인됩니다</div>
  </div>
</div>
