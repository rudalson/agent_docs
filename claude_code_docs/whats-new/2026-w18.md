# 18주차 · 2026년 4월 27일 – 5월 1일

> Git Bash 없이 실행되는 Windows용 Claude Code, 브라우저 콜백이 localhost에 도달할 수 없을 때 붙여넣은 OAuth 코드를 수락하는 claude auth login, 프로젝트별 로컬 상태를 정리하는 claude project purge, /resume에 PR URL을 붙여넣어 해당 PR을 생성한 세션을 찾는 기능.

  <p className="digest-feature-lede"><code>claude auth login</code>은 이제 브라우저 콜백이 localhost에 도달할 수 없을 때 터미널에 직접 붙여넣은 OAuth 코드를 수락합니다. 이는 로컬 포트로의 리디렉션이 작동하지 않는 WSL2, SSH 세션 및 컨테이너를 지원합니다. 또한 이번 릴리스에서는 느리거나 프록시된 연결 및 IPv6 전용 devcontainer에서의 로그인 타임아웃 문제도 해결되었습니다.</p>

  <p className="digest-feature-try">로그인한 후 브라우저에서 코드를 붙여넣으세요:</p>

  ```bash theme={null}
  claude auth login
  ```

  <p className="digest-feature-lede">트랜스크립트, 작업, 파일 기록, 프로젝트의 구성 항목 등 프로젝트에 대한 모든 Claude Code 상태를 삭제합니다. 미리 보기를 위한 `--dry-run`, 확인을 건너뛰기 위한 `-y`/`--yes`, 선택을 위한 `-i`/`--interactive`, 모든 프로젝트를 정리하기 위한 `--all`을 지원합니다.</p>

  <p className="digest-feature-try">삭제될 항목 미리 보기:</p>

  ```bash theme={null}
  claude project purge --dry-run
  ```


  <p className="digest-feature-lede"><code>gh pr create</code>로 풀 리퀘스트를 생성하면 Claude Code가 이를 해당 작업을 수행한 세션과 연결합니다. 이제 이름을 기억하지 않고도 PR URL만으로 해당 세션으로 돌아갈 수 있습니다.</p>

  <p className="digest-feature-try">세션 선택기 열기:</p>

  ```text Claude Code theme={null}
  > /resume
  ```

  <p className="digest-feature-try">선택기에 PR URL을 붙여넣으세요. 첫 번째 문자를 붙여넣으면 검색 모드로 진입하며, 해당 PR을 생성한 세션으로 목록이 필터링됩니다. Enter를 눌러 재개하세요. GitHub, GitHub Enterprise, GitLab, Bitbucket의 풀 및 머지 리퀘스트 URL이 모두 작동합니다.</p>

  ```text Claude Code theme={null}
  https://github.com/your-org/your-repo/pull/1234
  ```

  <p className="digest-feature-try">PR로 이미 필터링된 상태로 선택기를 열려면 명령줄에서 PR 번호를 전달하세요:</p>

  ```bash theme={null}
  claude --from-pr 1234
  ```

<div className="digest-wins">

  <div className="digest-wins-grid">
    <div>MCP 서버는 구성에서 <code>alwaysLoad: true</code>를 설정하여 도구 검색 연기를 옵트아웃할 수 있으므로, 해당 서버의 모든 도구를 항상 사용할 수 있습니다</div>
    <div>새로운 <code>claude plugin prune</code>은 고립된 자동 설치 플러그인 의존성을 제거하며, <code>plugin uninstall --prune</code>은 연쇄적으로 제거를 수행합니다</div>
    <div><code>/skills</code>에는 이제 타이핑하여 필터링하는 검색 상자가 있어 스크롤 없이도 긴 목록에서 스킬을 찾을 수 있습니다</div>
    <div><code>PostToolUse</code> 훅은 MCP 도구뿐만 아니라 모든 도구에 대해 <code>hookSpecificOutput.updatedToolOutput</code>을 통해 도구 출력을 대체할 수 있습니다</div>
    <div>새로운 <a href="/docs/docs/en/ultrareview"><code>claude ultrareview</code></a> 하위 명령은 CI 또는 스크립트에서 대화형이 아닌 방식으로 <code>/ultrareview</code>를 실행합니다. 결과를 stdout에 출력하고(원시 출력은 <code>--json</code>), 완료 시 0, 실패 시 1로 종료합니다</div>
    <div><code>--dangerously-skip-permissions</code>는 이제 <code>.claude/</code>, <code>.git/</code>, <code>.vscode/</code>, 쉘 구성 파일 및 이전에 보호되던 기타 경로에 대한 쓰기 프롬프트를 우회하며, 파괴적인 제거 명령은 안전 장치로서 여전히 프롬프트를 표시합니다</div>
    <div><code>/model</code> 선택기는 <code>ANTHROPIC\_BASE\_URL</code>이 Anthropic 호환 게이트웨이를 가리킬 때 게이트웨이의 <code>/v1/models</code> 엔드포인트에서 모델을 나열할 수 있습니다. v2.1.129부터는 <code>CLAUDE\_CODE\_ENABLE\_GATEWAY\_MODEL\_DISCOVERY=1</code>로 옵트인하세요</div>
    <div>시작 시 일시적 오류가 발생한 MCP 서버는 연결이 끊긴 상태로 유지되는 대신 최대 3회까지 자동 재시도합니다</div>
    <div><code>ANTHROPIC\_BEDROCK\_SERVICE\_TIER</code>는 Amazon Bedrock 서비스 계층(<code>default</code>, <code>flex</code> 또는 <code>priority</code>)을 선택합니다</div>
    <div><code>/terminal-setup</code>은 iTerm2의 클립보드 액세스 설정을 활성화하여 tmux를 포함한 환경에서 <code>/copy</code>가 작동하도록 합니다</div>
    <div>Google Cloud의 Agent Platform은 이제 X.509 인증서 기반 Workload Identity Federation (mTLS ADC)을 지원합니다</div>
    <div>주요 메모리 누수 수정: 이미지가 많은 세션, 대규모 트랜스크립트 기록에서의 <code>/usage</code>, 진행률 이벤트가 없는 장시간 실행 도구</div>
