# 27주차 · 2026년 6월 29일 – 7월 3일

> Claude Sonnet 5가 기본 모델이 되고, Chrome의 Claude가 정식 버전(GA)이 되며, 서브에이전트가 기본적으로 백그라운드에서 실행되고, Linux용 Claude Desktop 베타가 출시되며, /radio로 Claude FM을 청취.

  <p className="digest-feature-try">이름으로 Sonnet 5로 전환하거나 모델 선택기에서 선택하세요:</p>

  ```text Claude Code theme={null}
  > /model claude-sonnet-5
  ```

  <p className="digest-feature-lede">Anthropic 직접 플랜을 사용하는 모든 사용자에게 Chrome 통합 기능의 프리뷰가 종료되었습니다. Claude Code는 Chrome의 Claude 확장 프로그램을 통해 브라우저를 구동합니다: 탭을 열고, 페이지를 클릭하며, 양식을 작성하고, 콘솔 로그를 읽고, 로그인 상태를 공유하므로 문맥을 전환하지 않고도 구축한 앱을 테스트할 수 있습니다.</p>

  <a className="digest-feature-link" href="/docs/docs/en/chrome">Chrome과 함께 Claude Code 사용하기</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">서브에이전트 기본 백그라운드 실행</span>
    <span className="digest-feature-pill">v2.1.198</span>
  </div>

  <p className="digest-feature-lede">Claude는 이제 기다리기 위해 대화를 일시 중지하는 대신 서브에이전트가 실행되는 동안 계속 작업하고 완료되면 결과를 가져옵니다. 계속하기 전에 결과가 필요한 경우 Claude는 여전히 전경(foreground)에서 서브에이전트를 실행하며, 백그라운드 서브에이전트는 주 세션에서 모든 권한 프롬프트를 표시합니다. <code>background</code> 프론트매터 필드로 서브에이전트의 동작을 고정하세요.</p>

  <a className="digest-feature-link" href="/docs/docs/en/sub-agents#run-subagents-in-foreground-or-background">전경 또는 백그라운드에서 서브에이전트 실행</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/artifacts">아티팩트(Artifacts)</a>가 이제 정식 출시되어 Team 및 Enterprise 외에도 Pro 및 Max 플랜에 포함됩니다</div>
    <div>관리자는 조직 콘솔에서 <a href="/docs/docs/en/model-config#organization-default-model">조직 기본 모델</a>을 설정할 수 있습니다. 모델을 직접 선택하지 않은 경우 <code>/model</code>에 "Org default"로 표시됩니다</div>
    <div><code>/skill-a /skill-b do XYZ</code>와 같이 중첩된 스킬 호출은 이제 첫 번째뿐만 아니라 선두 스킬을 최대 5개까지 로드합니다</div>
    <div><code>AskUserQuestion</code> 대화 상자는 더 이상 기본적으로 자동 계속 진행하지 않습니다. <code>/config</code>를 통해 유휴 타임아웃을 옵트인하세요</div>
    <div>"default" 권한 모드가 이제 CLI, `--help`, VS Code, JetBrains 전반에서 "Manual"로 지정됩니다. `default`와 함께 `--permission-mode manual`도 허용됩니다</div>
    <div>새로운 <code>/dataviz</code> 스킬은 실행 가능한 색상 팔레트 검증기를 포함하여 차트 및 대시보드 디자인 지침을 제공합니다</div>
    <div>내장된 Explore 에이전트는 이제 Haiku에서 실행되는 대신 기본 세션의 모델(Opus로 제한됨)을 상속받습니다</div>
    <div><code>claude agents</code>에서 실행된 백그라운드 에이전트는 멈춰서 묻는 대신 워크트리에서 코드 작업을 마치면 커밋, 푸시 및 드래프트 PR을 엽니다</div>
    <div><code>code-reviewer</code>와 같이 하이픈이 들어간 식별자가 있는 훅 매처는 이제 부분 문자열 일치 대신 정확히 일치합니다. 하이픈이 있는 MCP 서버의 모든 도구를 일치시키려면 <code>mcp\_\_brave-search\_\_.\*</code>을 사용하세요</div>
    <div>사용 한도와 무관한 일시적 서버 요율 제한 오류는 이제 세션 턴을 실패 처리하는 대신 구독자의 경우 지연 후 자동으로 재시도됩니다</div>
    <div>스트리밍 유휴 감시 장치(idle watchdog)가 이제 모든 제공업체에 대해 기본적으로 켜집니다: 응답 스트림이 5분 동안 이벤트를 생성하지 않으면 중단하고 재시도합니다(비활성화하려면 <code>CLAUDE\_ENABLE\_STREAM\_WATCHDOG=0</code>)</div>
  </div>
</div>
