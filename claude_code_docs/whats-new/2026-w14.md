    <span className="digest-feature-title">깜빡임 없는 렌더링 (Flicker-free rendering)</span>
    <span className="digest-feature-pill">v2.1.89</span>
  </div>

  <p className="digest-feature-lede">가상화된 스크롤백을 제공하는 새로운 대체 화면(alt-screen) 렌더러를 옵트인하세요. 프롬프트 입력이 하단에 고정된 상태로 유지되고, 마우스 선택이 긴 대화에서도 작동하며, 다시 그릴 때 발생하는 깜빡임이 사라졌습니다. 되돌리려면 <code>CLAUDE\_CODE\_NO\_FLICKER</code> 설정을 해제하세요.</p>

  <Frame>
    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/CfffsX01JHFnIKvD/images/whats-new/flicker-free.mp4?fit=max&auto=format&n=CfffsX01JHFnIKvD&q=85&s=7719e35e52a3f9734b0cf69edac333ad" data-path="images/whats-new/flicker-free.mp4" />
  </Frame>

  <p className="digest-feature-try">환경 변수를 설정하고 Claude Code를 재시작하세요:</p>

  ```bash theme={null}
  export CLAUDE_CODE_NO_FLICKER=1
  claude
  ```

  <a className="digest-feature-link" href="/docs/docs/en/fullscreen">전체 화면 렌더링</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">MCP 결과 크기 재정의 (MCP result-size override)</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">MCP 서버 작성자는 이제 도구의 <code>tools/list</code> 항목에서 <code>anthropic/maxResultSizeChars</code>를 설정하여 최대 50만 자의 하드 상한선까지 특정 도구의 잘림 상한선을 늘릴 수 있습니다. 상한선은 이전에는 전역적이었기 때문에 데이터베이스 스키마나 전체 파일 트리처럼 본질적으로 대형 페이로드를 가끔 반환하는 도구는 기본 한도에 도달하여 파일 참조와 함께 디스크에 저장되었습니다. 도구별 재정의를 사용하면 도구에 정말 필요할 때 해당 결과를 인라인으로 유지합니다.</p>

  <p className="digest-feature-try">서버의 <code>tools/list</code> 응답에서 도구에 주석을 추가하세요:</p>

  ```json highlight={5} theme={null}
  {
    "name": "get_schema",
    "description": "Returns the full database schema",
    "_meta": {
      "anthropic/maxResultSizeChars": 500000
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/en/mcp#raise-the-limit-for-a-specific-tool">MCP 참조 문서</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">PATH에 플러그인 실행 파일 추가</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">플러그인 루트의 <code>bin/</code> 디렉터리에 실행 파일을 배치하면 플러그인이 활성화되어 있는 동안 Claude Code가 해당 디렉터리를 Bash 도구의 <code>PATH</code>에 추가합니다. Claude는 절대 경로나 래퍼 스크립트 없이 모든 Bash 도구 호출에서 바이너리를 순수 명령으로 호출할 수 있습니다. 해당 바이너리를 호출하는 명령, 에이전트 및 훅 옆에 CLI 헬퍼를 함께 패키징하는 데 편리합니다.</p>

  <p className="digest-feature-try">플러그인 루트에 <code>bin/</code> 디렉터리를 추가하세요:</p>

  ```text highlight={4, 5} theme={null}
  my-plugin/
  ├── .claude-plugin/
  │   └── plugin.json
  └── bin/
      └── my-tool
  ```

  <a className="digest-feature-link" href="/docs/docs/en/plugins-reference#file-locations-reference">플러그인 참조 문서</a>
</div>
