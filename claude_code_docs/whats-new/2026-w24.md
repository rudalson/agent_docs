# 24주차 · 2026년 6월 8일–12일

> /cd 명령을 사용하여 세션을 새 디렉토리로 이동하고, 서브에이전트가 자체 서브에이전트를 생성할 수 있도록 하며, 안전 모드(safe mode)를 사용하여 잘못된 구성을 문제 해결.

  <p className="digest-feature-lede">새로운 <code>/cd</code> 명령은 프롬프트 캐시를 재구축하지 않고 현재 세션을 다른 작업 디렉토리로 이동합니다: 새 디렉토리의 <code>CLAUDE.md</code>는 시스템 프롬프트를 교체하는 대신 메시지로 추가됩니다. 세션은 새 디렉토리의 프로젝트 저장소로 재배치되므로 `--resume` 및 `--continue`가 거기에서 찾을 수 있습니다. 이전에 작업하지 않은 디렉토리인 경우 Claude가 해당 디렉토리를 신뢰할지 묻는 프롬프트를 표시합니다.</p>

  <p className="digest-feature-try">재시작 없이 세션을 다른 프로젝트로 이동:</p>

  ```text Claude Code theme={null}
  > /cd ../other-project
  ```

  <p className="digest-feature-lede">서브에이전트가 이제 자체 서브에이전트를 생성할 수 있습니다. 프롬프트 아래의 서브에이전트 패널에는 전체 트리가 표시됩니다: 각 행에는 하위 구성 요소의 수와 <code>main</code>으로 돌아가는 경로가 표시됩니다. 서브에이전트 체인은 제어 불능의 동시 트리를 방지하기 위해 최대 5단계 깊이로 제한됩니다.</p>

  <p className="digest-feature-try">에이전트 뷰를 열어 작업이 확산됨에 따라 중첩된 트리를 관찰하세요:</p>

  ```text Claude Code theme={null}
  > /agents
  ```

  <a className="digest-feature-link" href="/docs/docs/en/sub-agents#spawn-nested-subagents">중첩된 서브에이전트 생성</a>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">안전 모드로 문제 해결</span>
    <span className="digest-feature-pill">v2.1.169</span>
  </div>

  <p className="digest-feature-lede">모든 커스터마이징을 비활성화한 상태로 시작하려면 `--safe-mode`로 Claude Code를 시작하거나 <code>CLAUDE\_CODE\_SAFE\_MODE</code>를 설정하세요: <code>CLAUDE.md</code>, 스킬, 플러그인, 훅, MCP 서버, 커스텀 명령 및 에이전트가 로드되지 않습니다. 인증, 모델 선택, 내장 도구 및 권한은 여전히 작동합니다. 안전 모드에서 문제가 사라지면 해당 구성 요소 중 하나가 원인입니다.</p>

  <p className="digest-feature-try">잘못된 구성을 격리하기 위해 깨끗한 세션을 시작하세요:</p>

  ```bash terminal theme={null}
  claude --safe-mode
  ```

</div>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/model-config#fallback-model-chains"><code>fallbackModel</code></a>은 기본 모델이 과부하되거나 사용할 수 없을 때 순서대로 시도할 수 있는 대체 모델을 최대 3개까지 구성하며, `--fallback-model`은 이제 대화형 세션에도 적용됩니다</div>
    <div>세션 제목이 이제 대화 언어로 생성됩니다. <code>language</code> 설정으로 특정 언어를 고정하세요</div>
    <div>`claude agents --json`에 완료된 세션과 새로운 <code>id</code> 및 <code>state</code> 필드를 포함하기 위한 `--all`이 추가되었으며, 차단되거나 새로 디스패치된 세션이 더 이상 누락되지 않습니다</div>
    <div><code>/plugin</code>에서 마켓플레이스의 플러그인을 탐색할 때 검색창이 제공됩니다</div>
    <div>새로운 <code>disableBundledSkills</code> 설정 및 <code>CLAUDE\_CODE\_DISABLE\_BUNDLED\_SKILLS</code>는 내장된 스킬, 워크플로우 및 내장 명령을 모델에서 숨깁니다</div>
    <div>거부 규칙은 도구 이름 위치에서 글롭(glob)을 허용하므로 <code>"\*"</code>는 모든 도구를 거부하며, 거부 규칙의 알 수 없는 도구 이름은 이제 시작 시 경고를 표시합니다</div>
    <div>교차 세션 메시징이 강화되었습니다: 다른 세션에서 <code>SendMessage</code>를 통해 전달된 메시지는 더 이상 사용자 권한을 가지지 않으며, 자동 모드에서 차단됩니다</div>
    <div>Amazon Bedrock은 <code>AWS\_REGION</code>이 설정되지 않은 경우 <code>\~/.aws</code> 구성 파일에서 AWS 리전을 읽으며, <code>/status</code>는 리전의 출처를 보여줍니다</div>
    <div>새로운 <code>enforceAvailableModels</code> 관리형 설정은 <code>availableModels</code> 허용 목록이 기본 모델도 제한하도록 합니다</div>
    <div>Chrome의 Claude 브라우저 도구는 이제 도구당 하나씩 호출하는 대신 단일 배치 호출로 로드됩니다</div>
    <div><code>claude update</code>는 아무 반응이 없는 대신 다운로드 전에 대상 버전을 발표합니다</div>
    <div>새로운 <code>footerLinksRegexes</code> 설정은 푸터 행에 정규식 일치 링크 배지를 추가합니다</div>
  </div>
