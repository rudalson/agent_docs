# 23주차 · 2026년 6월 1일–5일

    <span className="digest-feature-pill">v2.1.158</span>
  </div>

  <p className="digest-feature-lede">자동 모드가 이제 Amazon Bedrock, Google Cloud's Agent Platform 및 Microsoft Foundry에서 Opus 4.7 및 Opus 4.8에 제공되어 써드파티 제공업체에서 권한 프롬프트를 백그라운드 안전성 검사로 대체합니다. <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE=1</code>을 설정하여 옵트인하세요.</p>

  <p className="digest-feature-try">써드파티 제공업체에서 옵트인한 후 Shift+Tab으로 자동 모드로 전환하세요:</p>

  ```bash terminal theme={null}
  export CLAUDE_CODE_ENABLE_AUTO_MODE=1
  ```

  <a className="digest-feature-link" href="/docs/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">써드파티 제공업체에서의 자동 모드</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">더 안전한 자동 편집</span>
    <span className="digest-feature-pill">v2.1.160</span>
  </div>

  <p className="digest-feature-lede">Claude Code는 이제 <code>acceptEdits</code> 모드에서도 코드를 실행할 수 있는 파일을 쓰기 전에 프롬프트를 표시합니다. 보호 대상 파일 세트에는 <code>.zshenv</code> 및 <code>.bash\_login</code>과 같은 쉘 시작 파일, <code>\~/.config/git/</code> 하위의 git 구성, <code>.npmrc</code>, <code>.bazelrc</code>, <code>.pre-commit-config.yaml</code>과 같은 빌드 도구 구성이 포함됩니다. 이러한 쓰기는 <code>bypassPermissions</code>를 제외한 어떤 모드에서도 자동 승인되지 않습니다.</p>

  <p className="digest-feature-try">acceptEdits 모드에서 작업하세요. 이제 Claude가 이러한 파일을 쓰기 전에 일시 정지합니다:</p>

  ```bash terminal theme={null}
  claude --permission-mode acceptEdits
  ```

  <a className="digest-feature-link" href="/docs/docs/en/permission-modes#protected-paths">보호된 경로</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">/plugin list로 설치된 플러그인 나열</span>
    <span className="digest-feature-pill">v2.1.163</span>
  </div>

  <p className="digest-feature-lede">새로운 <code>/plugin list</code> 명령은 <code>/plugin</code> 메뉴를 열지 않고도 설치된 플러그인을 인라인으로 출력하며, 쉘에서 <code>claude plugin list</code>로도 사용할 수 있습니다. 대화형 형식에서는 해당 상태의 플러그인만 표시하도록 `--enabled` 또는 `--disabled`를 추가할 수 있습니다.</p>

  <p className="digest-feature-try">현재 활성화된 플러그인 나열:</p>

  ```text Claude Code theme={null}
  > /plugin list --enabled
  ```

  <a className="digest-feature-link" href="/docs/docs/en/plugins-reference#plugin-list">플러그인 명령어</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">관리형 배포를 위한 버전 요구 사항</span>
    <span className="digest-feature-pill">v2.1.163</span>
  </div>

  <p className="digest-feature-lede"><code>requiredMinimumVersion</code> 및 <code>requiredMaximumVersion</code>이라는 두 가지 관리형 설정을 통해 조직에서 승인된 Claude Code 버전 범위를 요구할 수 있습니다. 범위를 벗어난 클라이언트는 시작 시 종료되고 사용자에게 조직의 방법에 따라 업데이트하도록 안내합니다. <code>claude update</code>, <code>claude install</code>, <code>claude doctor</code>는 사용자가 계속 복구할 수 있도록 작동을 유지합니다.</p>

  <p className="digest-feature-try">이전 클라이언트가 시작되지 않도록 관리형 설정에 하한선을 추가하세요:</p>

  ```json managed-settings.json theme={null}
  {
    "requiredMinimumVersion": "2.1.163"
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/en/admin-setup#decide-what-to-enforce">적용할 항목 결정</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">기타 개선 사항</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/workflows">동적 워크플로우</a>의 트리거 키워드가 <code>workflow</code>에서 <code>ultracode</code>로 변경되었습니다. 자신만의 단어로 워크플로우를 요청해도 여전히 작동하며, 프롬프트에서 키워드가 보라색으로 강조 표시됩니다</div>
    <div><a href="/docs/docs/en/hooks">Stop 및 SubagentStop 훅</a>은 <code>hookSpecificOutput.additionalContext</code>를 반환하여 오류로 처리되는 대신 Claude에게 피드백을 제공하고 턴을 계속 진행할 수 있습니다</div>
    <div><code>claude mcp</code> list, get 및 add는 더 이상 비밀정보를 출력하지 않습니다: 환경 변수 참조가 확장되지 않으며 자격 증명 헤더 및 URL 비밀정보가 가려집니다(redact)</div>
    <div>병렬 도구 배치에서 실패한 Bash 명령이 더 이상 다른 명령을 취소하지 않습니다. 각 도구는 독립적으로 자체 결과를 반환합니다</div>
    <div>단일 파일 <code>grep</code>, <code>egrep</code> 또는 <code>fgrep</code>으로 파일 목록을 조회한 경우 해당 파일을 편집할 때 더 이상 별도의 Read가 필요하지 않습니다</div>
    <div>자동 완성 메뉴에서 명령을 클릭하면 즉시 실행되는 대신 프롬프트에 채워집니다. 실행하려면 Enter를 누르세요</div>
    <div>`--tools`에서 <code>Grep</code> 또는 <code>Glob</code>를 나열하면 실시간 검색이 내장된 기본 빌드에서 이러한 이름을 무시하는 대신 전용 검색 도구를 제공합니다</div>
    <div><code>/effort</code>는 이제 선택한 수준이 새 세션의 기본값으로 영구 유지되는지 확인해 줍니다</div>
    <div><code>OTEL\_RESOURCE\_ATTRIBUTES</code> 값은 이제 메트릭 데이터 포인트에 레이블로 첨부되므로 팀이나 리포지토리와 같은 커스텀 차원별로 사용량 메트릭을 분할할 수 있습니다</div>
    <div>에디터 브랜드 변경에 따라 <code>/ide</code>, <code>/terminal-setup</code>, <code>/scroll-speed</code>에서 Windsurf 이름이 Devin Desktop으로 변경되었습니다</div>
    <div><code>/btw</code>에 원시 마크다운 답변을 클립보드로 복사하는 <code>c to copy</code> 단축키가 추가되었습니다</div>
  </div>
</div>
