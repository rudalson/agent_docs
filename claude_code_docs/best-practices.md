# Claude Code 베스트 프랙티스 (Best practices)

> 환경 구성부터 병렬 세션을 통한 확장에 이르기까지, Claude Code를 최대한 활용하기 위한 팁과 패턴을 소개합니다.

Claude Code는 자율 에이전트 기반의 코딩 환경입니다. 질문에 답하고 기다리기만 하는 일반적인 챗봇과 달리, Claude Code는 사용자의 파일을 읽고, 명령을 실행하며, 코드를 수정하고 문제를 자율적으로 해결할 수 있습니다.

대부분의 베스트 프랙티스는 하나의 제약 사항을 기반으로 합니다: **Claude의 컨텍스트 창은 빠르게 차오르며, 채워질수록 성능이 저하된다는 점**입니다.

## 핵심 핵심 정리

### 1. 작업 검증 방법 제공하기
Claude에게 실행 가능한 테스트, 빌드, 비교용 스크린샷 등의 검증 수단을 제공하세요. 결과를 직접 검증하고 통과할 때까지 반복하도록 만듭니다.

### 2. 탐색 -> 계획 -> 구현 흐름 따르기
* **탐색(Explore)**: Plan 모드에서 파일을 읽고 질문에 답하도록 합니다.
* **계획(Plan)**: 자세한 구현 계획을 작성하도록 요청합니다 (`Ctrl+G`로 직접 수정 가능).
* **구현(Implement)**: Plan 모드를 해제하고 계획에 맞춰 코딩하도록 합니다.
* **커밋(Commit)**: PR 및 설명이 담긴 커밋을 생성합니다.

### 3. 프롬프트에 구체적인 컨텍스트 제공
* `@` 기호로 관련 파일 명시
* 이미지 직접 붙여넣기
* 문제의 증상, 관련 디렉토리, 성공 기준을 구체적으로 서술

### 4. CLAUDE.md 및 환경 설정
* 프로젝트 루트에 `CLAUDE.md`를 두고 가이드라인 작성
* `/init` 명령어로 기본 `CLAUDE.md` 생성
* 불필요하고 당연한 내용은 제외하여 컨텍스트 낭비 방지
