# 세션 출력을 아티팩트(Artifacts)로 공유하기

> 아티팩트는 Claude Code의 작업을 비공개로 유지하거나, 조직과 공유하거나, 공개 링크로 게시할 수 있는 실시간 대화형 페이지로 변환해 줍니다.

<Note>
  아티팩트는 Pro, Max, Team 및 Enterprise 요금제에서 사용할 수 있으며 [`/login`](/docs/en/setup#authenticate)으로 로그인된 세션이 필요합니다. 전체 요구 사항은 [사용 가능 환경](#availability)을 참고하세요.
</Note>

아티팩트는 Claude Code가 세션에서 claude.ai의 비공개 URL로 게시하는 실시간 대화형 웹 페이지입니다. 브라우저에서 열 수 있으며 세션이 계속됨에 따라 해당 위치에서 실시간으로 업데이트됩니다. 다른 사람에게 보여주고 싶다면 페이지 헤더에서 공유하세요. 예를 들어 주석이 달린 diff를 통해 풀 리퀘스트를 리뷰어에게 설명하거나, 세션 데이터로 대시보드를 생성하거나, Claude가 작업하는 동안 채워지는 조사 타임라인을 유지하는 데 아티팩트를 사용할 수 있습니다.

## 아티팩트를 사용해야 하는 시점

터미널 텍스트가 Claude가 생성한 내용(한 줄 한 줄 읽는 것보다 직접 보고 상호작용하기 쉬운 출력)을 전달하기에 적절하지 않을 때 아티팩트를 사용하세요. Claude는 코드베이스 및 [연결된 도구(MCP)](/docs/en/mcp)를 통해 가져온 데이터를 포함하여 세션이 접근할 수 있는 모든 항목으로부터 페이지를 작성하므로, 텍스트 설명으로는 몇 단락이 걸릴 내용을 시각적으로 보여줄 수 있습니다.

예를 들어 Claude에게 다음을 요청할 수 있습니다:

* 주석이 달린 diff와 함께 풀 리퀘스트를 리뷰어에게 설명
* 세션이 이미 가져온 데이터로 대시보드 렌더링
* 여러 디자인 또는 구현 옵션을 나란히 배치
* 긴 작업이 실행되는 동안 채워지는 조사 타임라인 유지
* Slack에 출력을 붙여넣는 대신 팀원에게 링크 전송

## 아티팩트 생성하기

출력이 페이지 형태에 적합할 때 Claude가 스스로 아티팩트를 게시하거나, 직접 요청할 수 있습니다. 

```text wrap theme={null}
이 PR을 인라인 diff 주석과 함께 둘러볼 수 있는 아티팩트를 만들어줘.
```

```text wrap theme={null}
지난주 서비스별 배포 실패 내역을 대시보드 아티팩트로 만들고 조사가 진행됨에 따라 업데이트해줘.
```

Claude는 프로젝트의 HTML 또는 Markdown 파일에 페이지를 작성한 다음 이를 게시합니다. 새 아티팩트를 게시하기 전에 Claude Code는 권한을 요청합니다. 게시를 승인하려면 **Yes**를 선택하세요. Claude가 URL을 출력하고 브라우저가 새 페이지로 열립니다. 터미널에서 가장 최근 아티팩트를 다시 열려면 언제든지 `Ctrl+]`를 누르세요.

자동으로 브라우저가 열리는 것을 원하지 않는 경우 환경 변수에 `CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0`을 설정하세요.

## 아티팩트 공유하기

새 아티팩트는 작성자에게만 보입니다. 공유하려면 브라우저에서 아티팩트를 열고 페이지 헤더의 **Share** 컨트롤을 사용하세요.

* **조직 내부 공유**: Team 및 Enterprise 요금제에서는 조직 내 특정 사람 또는 전체에게 접근 권한을 부여할 수 있습니다.
* **공개 공유**: 로그인 없이 인터넷의 누구나 열 수 있는 링크를 공유합니다. Pro 및 Max 요금제에서는 공개 링크가 유일한 공유 방법입니다. Team 및 Enterprise 요금제에서는 관리자가 [조직에 대해 활성화](#control-public-sharing)할 때까지 공개 공유가 비활성화됩니다.

## 제한 사항

각 아티팩트는 하나의 독립된 HTML 페이지입니다.

| 제한 요소 | 영향 |
| :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 외부 요청 금지 | CSP는 데이터 URI 형태로 임베드된 이미지 등을 제외하고 외부 서버로의 스크립트, 스타일시트, 이미지, fetch 요청 등을 차단합니다. |
| 백엔드 없음 | 아티팩트는 정적 페이지입니다. 폼 제출 데이터를 저장하거나 사용자를 직접 인증할 수 없습니다. |
| 단일 페이지 | 상대 링크가 연결되지 않습니다. 다중 섹션 콘텐츠의 경우 앵커 링크를 사용합니다. |

## 사용 불가능하게 설정 (Disable)

조직 설정과 관계없이 세션에서 아티팩트를 끄려면 다음 중 하나를 사용하세요:

* [설정 파일](/docs/en/settings): `"disableArtifact": true`
* [환경 변수](/docs/en/env-vars): `CLAUDE_CODE_DISABLE_ARTIFACT=1`
* [권한 규칙](/docs/en/permissions): `permissions.deny`에 `Artifact` 추가
