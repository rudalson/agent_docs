# 에이전트 뷰(Agent view)로 여러 에이전트 관리하기

> 단일 화면에서 여러 Claude Code 세션을 전달(dispatch)하고 관리하세요. 에이전트 뷰는 각 세션이 수행 중인 작업과 입력을 기다리는 세션을 보여줍니다.

`claude agents`로 열 수 있는 에이전트 뷰는 모든 백그라운드 세션을 한 화면에서 관리할 수 있는 공간입니다: 실행 중인 작업, 사용자 입력을 기다리는 작업, 완료된 작업을 한눈에 볼 수 있습니다. 새 세션을 전달하고, 트랜스크립트를 스크롤하는 대신 한눈에 상태를 파악하며, 도움이 필요한 세션에만 개입하세요. 각 백그라운드 세션은 터미널이 연결되어 있지 않아도 계속 실행되는 완전한 Claude Code 대화이므로 언제든지 열어서 답장하고 창을 닫을 수 있습니다.

<img src="https://mintcdn.com/claude-code/1B48Qz2Z9hac4SLG/images/agent-view-dark.png?fit=max&auto=format&n=1B48Qz2Z9hac4SLG&q=85&s=a5bed7434bae368faea3a8f023b52aa2" className="hidden dark:block" alt="터미널 내 에이전트 뷰(다크 모드)" width="1772" height="780" data-path="images/agent-view-dark.png" />

에이전트 뷰는 모든 단계를 지켜볼 필요 없이 Claude가 독립적으로 수행할 수 있는 작업이 여러 개 있을 때 유용합니다. 버그 수정, 풀 리퀘스트 리뷰, 간헐적 테스트(flaky-test) 조사를 3개의 행으로 전달하고 다른 창에서 작업을 계속하다가, 특정 행이 입력 요청을 하거나 결과를 표시할 때 다시 확인하세요.

에이전트 세션에서 직접 작업하고 싶다면 해당 행에 연결(attach)하여 전체 대화로 들어갈 수 있습니다.

에이전트 뷰를 서브에이전트, 에이전트 팀, 워크트리와 비교하려면 [에이전트 병렬 실행하기](/docs/en/agents)를 참고하세요.

<Note>
  에이전트 뷰는 연구 프리뷰 단계이며 Claude Code v2.1.139 이상이 필요합니다. `claude --version`으로 버전을 확인하세요. 기능이 발전함에 따라 인터페이스 및 단축키가 변경될 수 있습니다.
</Note>

## 빠른 시작

이 과정을 통해 핵심 에이전트 뷰 워크플로를 경험해 보세요: 작업 전달하기, Claude가 작업함에 따라 행 업데이트 관찰하기, 미리보기(peek)로 확인 및 답장하기, 전체 대화를 위해 연결(attach)하기. 전달한 세션은 에이전트 뷰를 닫은 후에도 계속 실행되므로 나중에 다시 돌아올 수 있습니다.

<Steps>
  <Step title="에이전트 뷰 열기">
    셸에서 다음 명령을 실행합니다:

    ```bash theme={null}
    claude agents
    ```

    에이전트 뷰가 열리고 하단에는 입력창이, 중앙에는 세션이 시작됨에 따라 채워지는 테이블이 나타납니다. 셸로 돌아가려면 언제든지 `Esc`를 누르세요. 세션은 떠나 있는 동안에도 계속 실행되며 다음 번에 에이전트 뷰를 열 때 다시 나타납니다.
  </Step>

  <Step title="세션 전달 (Dispatch)">
    작업을 설명하는 프롬프트를 입력하고 `Enter`를 누릅니다. 새로운 백그라운드 세션이 시작되고 해당 세션이 작업 중인지, 사용자 입력을 기다리는지, 완료되었는지를 나타내는 행으로 표시됩니다. 새 세션은 에이전트 뷰 헤더에 표시된 모델과 해당 디렉토리에서 `claude`를 실행할 때 적용되는 동일한 [권한 모드](#permission-mode-model-and-effort)를 사용합니다.

    여기서 입력하는 모든 프롬프트는 고유한 새 세션을 시작합니다. 다른 프롬프트를 입력하고 `Enter`를 누르면 후속 메시지를 보내는 대신 첫 번째 세션과 함께 두 번째 세션이 시작됩니다. 이런 방식으로 여러 세션을 병렬로 실행할 수 있습니다.

    각 세션은 구독 할당량을 독립적으로 사용하므로 한 번에 여러 개를 전달하기 전에 [제한사항](#limitations)을 확인하세요.
  </Step>

  <Step title="미리보기(Peek) 및 답장">
    화살표 키로 행을 선택하고 `Space`를 눌러 미리보기(peek) 패널을 엽니다. 전체 트랜스크립트 대신 세션의 가장 최근 출력이나 기다리고 있는 질문을 보여줍니다. 답장을 입력하고 `Enter`를 누르면 에이전트 뷰를 떠나지 않고도 답장을 보낼 수 있습니다.
  </Step>

  <Step title="연결(Attach) 및 분리(Detach)">
    전체 대화를 원할 때 행에서 `Enter` 또는 `→`를 눌러 연결합니다. 세션이 터미널을 점유하며 완전한 대화형 Claude Code 세션이 됩니다. 빈 프롬프트에서 `←`를 누르면 분리되어 테이블로 돌아옵니다.
  </Step>

  <Step title="기존 세션 가져오기">
    이 단계에는 실행 중인 세션이 필요합니다. 이전 단계를 따랐다면 이 터미널에 열려 있는 세션이 없을 것이므로, 다른 터미널에서 일반 `claude` 세션을 열고 먼저 메시지를 보내세요.

    이미 열려 있는 세션을 에이전트 뷰로 옮기려면 내부에서 `/bg`를 실행하거나, 빈 프롬프트에서 `←`를 눌러 백그라운드화하고 에이전트 뷰를 한 번에 열 수 있습니다. 아직 메시지가 없는 새 세션에서는 `/bg`가 먼저 메시지를 보내도록 요청하는 반면, `←`는 즉시 동작합니다. 세션은 계속 실행되며 전달한 세션들과 함께 행으로 나타납니다.
  </Step>
</Steps>

`claude` 대신 `claude agents`를 주 진입점으로 사용할 수 있습니다: 에이전트 뷰에서 모든 작업을 전달하고, 전체 대화가 필요할 때 연결하며, `←`를 눌러 테이블로 돌아옵니다.

## 세션 모니터링하기

`claude agents`를 실행하여 에이전트 뷰를 엽니다. 전체 터미널을 차지하며 상단에 고정된 세션과 입력이 필요한 세션을 포함해 상태별로 그룹화된 모든 세션을 나열합니다. 각 행에는 세션의 이름, 현재 작업, 세션 생성 시점부터 계산된 시간(age)이 표시됩니다. 완료된 세션의 시간은 실행에 걸린 시간으로 고정됩니다.

이름은 해당 세션의 [`/color`](/docs/en/commands)로 설정된 색상으로 표시됩니다.

기본적으로 목록에는 모든 프로젝트에서 시작한 모든 백그라운드 세션이 표시됩니다. 하나의 저장소에서 작업 중인 세션과 다른 워크트리의 세션이 모두 에이전트 뷰를 연 디렉토리에 상관없이 여기에 나타납니다. 목록을 특정 프로젝트로 구체화하려면 `--cwd`를 전달하세요:

```bash theme={null}
claude agents --cwd ~/projects/my-app
```

이 명령은 해당 디렉토리 하위에서 시작된 세션만 보여줍니다. `~/projects/my-app/.claude/worktrees/` 하위의 [워크트리로 이동한](#how-file-edits-are-isolated) 세션도 여전히 `~/projects/my-app`에 속하는 것으로 카운트됩니다.

다른 터미널에 열어둔 대화형 세션은 [백그라운드화](#from-inside-a-session)하기 전까지는 나타나지 않습니다. 세션이 생성한 [서브에이전트](/docs/en/sub-agents) 및 [팀원](/docs/en/agent-teams)은 별도의 행으로 나열되지 않습니다.

### 세션 상태 읽기

각 행은 상태를 나타내는 색상과 애니메이션이 있는 아이콘으로 시작합니다:

| 상태 | 아이콘 표시 | 의미 |
| :---------- | :------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Working | 애니메이션 | Claude가 적극적으로 도구를 실행하거나 응답을 생성 중 |
| Needs input | 노란색 | 질문 답변, 권한 결정, 샌드박스 호스트 허용, MCP 요청, MCP 인증 등 사용자가 직접 입력해야 하는 상황 |
| Idle | 흐림(Dimmed) | 세션이 할 일이 없으며 다음 프롬프트를 받을 준비가 됨 |
| Completed | 초록색 | 작업이 성공적으로 완료됨 |
| Failed | 빨간색 | 작업이 오류로 종료됨 |
| Stopped | 회색 | `Ctrl+X`나 `claude stop`으로 정지되었거나 외부에서 프로세스가 종료됨 |

아이콘 모양은 기본 프로세스의 실행 여부를 나타냅니다:

| 모양 | 의미 |
| :------------------ | :---------------------------------------------------------------------------------------- |
| `✻` 또는 애니메이션 `✽` | 세션 프로세스가 살아있고 즉시 응답함 |
| `∙` | 프로세스가 종료됨. 여전히 peek, reply, attach가 가능하며 Claude가 중단된 위치부터 재시작함 |
| `✢` | 반복 간 대기 중인 [`/loop`](/docs/en/scheduled-tasks) 세션. 실행 횟수와 카운트다운을 표시함 |

## 새로운 에이전트 전달 (Dispatch)

에이전트 뷰에서 새 백그라운드 세션을 전달하거나, 기존 대화형 세션을 백그라운드로 보내거나, 셸에서 직접 시작할 수 있습니다.

### 에이전트 뷰에서 전달하기

에이전트 뷰 하단 입력창에 프롬프트를 입력하고 `Enter`를 눌러 새 백그라운드 세션을 시작합니다. 세션 이름은 프롬프트를 기반으로 자동 설정되며, 나중에 `Ctrl+R`로 이름을 변경할 수 있습니다.

프롬프트 앞에 또는 내부에서 다음 형식을 사용하여 세션 시작 방식을 제어할 수 있습니다:

| 입력 | 효과 |
| :-------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<agent-name> <prompt>` | 첫 단어가 커스텀 [서브에이전트](/docs/en/sub-agents) 이름과 일치하면 해당 서브에이전트 설정으로 메인 에이전트 실행 |
| `@<agent-name>` | 프롬프트 어디에서나 커스텀 서브에이전트를 언급하여 메인 에이전트로 실행 |
| `@<repo>` | 저장소를 언급하여 해당 디렉토리에서 세션 실행 |
| `/<command>` | 스킬 및 명령어를 제안하여 프롬프트로 전달 |
| `! <command>` | Claude 세션 대신 셸 명령어를 백그라운드 작업으로 실행 |

### 셸에서 전달하기

`--bg` 또는 `--background`를 전달하여 바로 백그라운드로 이동하는 세션을 시작할 수 있습니다:

```bash theme={null}
claude --bg "investigate the flaky SettingsChangeDetector test"
```

특정 서브에이전트를 메인 에이전트로 실행하려면 `--agent`와 결합합니다:

```bash theme={null}
claude --agent code-reviewer --bg "address review comments PR 1234"
```

에이전트 뷰에 표시될 이름을 직접 지정하려면 `--name`을 전달하세요:

```bash theme={null}
claude --bg --name "flaky-test-fix" "investigate the flaky SettingsChangeDetector test"
```

백그라운드로 전송되면 short ID와 함께 다음과 같은 안내가 출력됩니다:

```text theme={null}
backgrounded · 7c5dcf5d · flaky-test-fix
  claude agents             list sessions
  claude attach 7c5dcf5d    open in this terminal
  claude logs 7c5dcf5d      show recent output
  claude stop 7c5dcf5d      stop this session
```

## 단축키 요약

| 단축키 | 동작 |
| :-------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------- |
| `↑` / `↓` | 행 간 이동 |
| `Enter` | 선택한 세션에 연결(attach), 또는 입력창에 텍스트가 있을 경우 전달(dispatch) |
| `Space` | 선택한 세션의 미리보기(peek) 패널 열기/닫기 |
| `Shift+Enter` | 전달 후 즉시 연결 |
| `→` | 선택한 세션에 연결 |
| `Ctrl+S` | 상태별/디렉토리별 그룹화 전환 |
| `Ctrl+T` | 선택한 세션 고정/고정 해제 |
| `Ctrl+R` | 선택한 세션 이름 변경 |
| `Ctrl+X` | 세션 정지; 2초 내 다시 누르면 삭제 |
| `Esc` | 미리보기 닫기, 입력창 비우기, 또는 종료 |
| `?` | 모든 단축키 도움말 보기 |
