# 자동 모드 (Auto Mode) 구성하기

> 자동 모드 분류기에 조직이 신뢰하는 저장소, 버킷 및 도메인을 지정합니다. 환경 컨텍스트를 설정하고, 기본 차단 및 허용 규칙을 재정의하며, auto-mode CLI 하위 명령으로 실제 적용되는 구성을 확인하세요.

[자동 모드](/docs/en/permission-modes#eliminate-prompts-with-auto-mode)는 돌이킬 수 없거나 파괴적이거나 환경 외부를 목표로 하는 모든 작업을 차단하는 분류기를 통해 도구 호출을 라우팅하여 일상적인 권한 확인 요청 없이 Claude Code가 실행될 수 있도록 합니다. 거부(Deny) 및 명시적 확인(Ask) 규칙은 분류기보다 먼저 평가되어 여전히 차단하거나 확인을 요청합니다. `autoMode` 설정 블록을 사용하여 해당 분류기에 조직이 신뢰하는 저장소, 버킷 및 도메인을 알려주면 일상적인 내부 작업이 차단되는 것을 방지할 수 있습니다.

기본적으로 분류기는 현재 작업 디렉토리와 구성된 원격 저장소만 신뢰합니다. 회사 소스 제어 조직에 푸시하거나 팀 클라우드 버킷에 기록하는 등의 작업은 `autoMode.environment`에 추가할 때까지 차단될 수 있습니다.

## 주요 개념

자동 모드를 구성할 때 주로 설정하는 항목은 다음과 같습니다:

1. `autoMode.environment`: 신뢰할 수 있는 소스 제어 저장소, 클라우드 버킷, 내부 도메인, 패키지 레지스트리 등을 지정합니다.
2. `autoMode.allow`: 특정 예외 허용 규칙을 추가합니다.
3. `autoMode.soft_deny` 및 `autoMode.hard_deny`: 파괴적인 동작이나 절대 넘지 말아야 할 보안 경계를 정의합니다.

구성 세부사항은 `claude auto-mode config` 명령어를 통해 손쉽게 확인할 수 있습니다.
